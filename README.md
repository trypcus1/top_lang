Добро пожаловать в репозиторий **TOP!** (произносится «Топ»). 
Это мой персональный экспериментальный язык программирования, который я разрабатываю с нуля на языке **Rust**. 

Моя главная цель — создать строго типизированный, лаконичный и невероятно читаемый язык, который будет понятен новичкам и при этом не будет раздражать опытных разработчиков своей избыточностью. Я не пытаюсь заменить Python или C++, я создаю инструмент, в котором код читается как естественный текст.

## 🌟 Ключевые особенности языка

### 1. Жёсткая типизация (Strict Typing)
В TOP! вы не можете просто сказать `x = 5`. Вы обязаны указать тип данных. Если вы попытаетесь присвоить строку числу — интерпретатор выдаст ошибку. Всего в языке **5 базовых типов**:
*   `numbers` — для целых чисел (`integer`) и дробных (`float`);
*   `words` — для всех текстовых данных (`string`);
*   `sherlock` — для булевых значений (`true` / `false`);
*   `collections` — для коллекций (списки, а в будущем — кортежи, множества и словари);
*   `nottype` — тип, означающий отсутствие значения или «пустоту» (`none`).

### 2. Нечувствительность к регистру
Забудьте о головной боли с `camelCase` или `snake_case`. В TOP! переменные `NUM`, `num` и `Num` — это **одна и та же переменная**. Это снижает количество глупых ошибок из-за опечаток.

### 3. Точки с запятой
В отличие от Python, где концом строки является перенос, в TOP! каждая инструкция заканчивается символом `;`. Это делает код строже и избавляет парсер от догадок.

### 4. Условия с характером
В языке есть привычные `if` и `else`, а также их синоним `when`. Но главная фишка — это конструкция `why`! Она работает как `if`, но перед выполнением ветки кода **печатает в консоль значение условия** (true или false). Идеально для отладки!

why n < 100 {
    # Если n меньше 100, программа выведет "why -> true" и выполнит блок
}

**TOP!** — это экспериментальный язык программирования, который я, **Куля Щепан Циприан**, создаю с нуля на Rust.  
Цель — сделать строго типизированный, лаконичный и невероятно понятный язык, который будет приятен новичкам и не будет раздражать опытных разработчиков.

> *«Я хочу, чтобы код на TOP! читался как хорошо написанная инструкция — без лишней шелухи и двусмысленностей.»*

---

## 🚀 Особенности

- **Жёсткая типизация** — каждый тип проверяется на этапе выполнения (пока что). Забыл указать тип? Ошибка. Присвоил строку числу? Ошибка. Всё честно.
- **Пять базовых типов**:
  - `numbers` — целые и дробные числа;
  - `words` — строки;
  - `sherlock` — булевы значения (`true` / `false`);
  - `collections` — списки и другие коллекции;
  - `nottype` — отсутствие значения (`none`).
- **Условия как в Python, но с изюминкой**:
  - `if`, `when` (синоним `if`) и `why` — специальная конструкция, которая *печатает* значение условия перед выполнением ветки.
